# 全局规则

## 沟通与旁白

接到任务先一句话说明要做什么，再动手，不要立刻埋头干活。

调用工具前后要有旁白/注释：

- 调用前：用「正在用……做……」的句式，一句话点明手段与目的。
- 调用后：一句话说明结果，例如成功、失败、关键发现、下一步依据。
- 同一批并行调用：一行前旁白，配一行后结论，不必每个子调用各写一句。
- 例：前「正在用 grep 搜这个报错从哪来」→ 后「定位到是配置项缺失」。
