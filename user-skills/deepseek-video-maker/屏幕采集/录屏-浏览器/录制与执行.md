# 录制与执行

## 录制 + 执行

```bash
browse execute --file prep.mjs            # 打开页面、改设置
browse recording start --session <id> --frame-rate 60 /tmp/xx.webm
browse execute --file take.mjs            # 只做动作，等待写在脚本里
browse recording stop --session <id>
```

`take.mjs` 骨架：

```js
const bar = page.locator('#sej-shadow-host');
await page.mouse.move(760, 520, { steps: 3 });        // 让假光标落到画面内
await page.waitForTimeout(800);                       // 起手留白
const chip = bar.locator('a.sej-drop-list-trigger', { hasText: '搜索' }).first();
const c = await chip.boundingBox();
await page.mouse.move(c.x + c.width / 2, c.y + c.height / 2, { steps: 26 });  // 悬停=展开
await page.waitForTimeout(1200);
```

## 控制跳转打开方式

想让跳转结果落在录制画面里，把「默认打开方式」改成**当前页**，录完改回**后台标签页**：

```js
await page.locator('#sej-shadow-host [title="设置菜单"]').first().click();
await page.waitForTimeout(900);
await page.locator('#sej-shadow-host select').first().selectOption('_self'); // 还原用 '_background'
await page.locator('#sej-shadow-host .sej-panel-close').first().click();
```
