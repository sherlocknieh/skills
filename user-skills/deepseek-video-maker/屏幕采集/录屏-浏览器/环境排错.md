# 环境排错

| 现象 | 结论 |
| --- | --- |
| MCP `browse execute` 里 `page` 一直是 undefined | 扩展 0.0.16 连接下拿不到页面句柄。**改用 CLI**：`browse execute --file x.mjs` |
| `browse status` 里 `tabs: 0`，用户明明开了窗口 | 扩展看不见用户标签；CLI 的 `execute` 会**自建**标签页，直接 `page.goto` 即可 |
| 起不了窗口、或扩展一直 0 tabs | 必须以 Wayland 方式启动（见 [启动浏览器](./启动浏览器.md)），并先删 `Singleton*` |
| `pkill -f "chrome ..."` 把自己 shell 杀了 | 用 `pkill -f '^/opt/google/chrome/chrome'` |
| 想要 1920×1080 | 做不到：本机屏幕逻辑分辨率上限 **1536×833**（dpr 2）；CDP 录制抓标签页表面，实际 **1520×776** |
| 录制里没有鼠标 | CDP 不采集系统光标，必须往页面注入假光标（见 [假光标](./假光标.md)） |
| 顶部出现「browse 已开始调试此浏览器」横幅，录进画面 | `chrome.debugger` 附加的强制提示，扩展侧关不掉；启动加 `--silent-debugger-extension-api`（见 [启动浏览器](./启动浏览器.md)） |
| 点引擎后「什么都没发生」 | 出站被打开到**后台标签页**，而后台标签录不到、也 adopt 不到 |
| 点分类芯片没展开列表 | **悬停才展开**；点击等于「点击分类直接搜索」，会直接在当前页搜索 |
| 百度页面能拍吗 | 不能，顶栏有登录昵称+头像。**Google 也有头像**。用**搜狗**或 **Bing** |
| 截图看太多导致 token 爆炸 | 一张图约 1200 token，只在关键节点看一次 |
