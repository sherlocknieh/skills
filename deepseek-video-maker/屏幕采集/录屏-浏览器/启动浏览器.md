# 启动浏览器

## 启 Chrome（Wayland，干净启动）

```bash
pkill -f '^/opt/google/chrome/chrome'; sleep 3
rm -f ~/.config/google-chrome/Singleton*
env -u DISPLAY -u XAUTHORITY WAYLAND_DISPLAY=wayland-0 setsid google-chrome \
  --ozone-platform=wayland --silent-debugger-extension-api --window-position=60,40 \
  "https://www.sogou.com/web?query=example.com" >/tmp/chrome.log 2>&1 &
```

## 说明

- 必须以 Wayland 方式启动，否则起不了窗口或扩展一直 0 tabs。
- 先删 `Singleton*`，避免残留锁。
- `pkill` 用 `pkill -f '^/opt/google/chrome/chrome'`，不要用 `pkill -f "chrome ..."`，否则会杀掉自己的 shell。
- `--silent-debugger-extension-api`：扩展一 attach 标签页，Chromium 就在顶部挂「browse 已开始调试此浏览器」横幅，
  扩展侧关不掉，会直接录进画面。只有带上这个启动参数才能静默。从桌面图标启动时，同样参数要加到
  `~/.local/share/applications/google-chrome.desktop` 的 `Exec` 行（改完须完全退出 Chrome 再启动）。
  代价是该开关静默所有扩展的调试警告，只在本机自用场景开。
